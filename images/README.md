# Placeholder for Profile Image

This directory should contain your profile image.

To add your profile image:
1. Replace this file with your profile photo
2. Name it `profile.jpg` (or update the reference in index.html)
3. Recommended size: 500x500 pixels or larger, square aspect ratio
4. Supported formats: JPG, PNG, WebP

The image will be automatically displayed as a circular profile photo on your homepage.
